PURPOSE
Nova is a local autonomous AI-agent runtime intended to inhabit a real game as a persistent character: perceive, remember, reflect, plan, and act. Current game body is Cataclysm: Dark Days Ahead (CDDA), official CleverRaven experimental Windows tiles/source based on cdda-experimental-2026-09-18-0640, original base commit 63a3cd00aadf2df23976544ae9983d062432fed8.

Local deliberative model: Ollama qwen2.5:7b.

CORE DESIGN INVARIANTS
1. Thought is permissive, action is strict. Nova may think/want anything, but only verified capabilities may affect the game.
2. Never fake game effects by mutating external state when a native CDDA action exists.
3. Evidence outranks model narration. Sensor/state facts constrain goals. Native before/after evidence verifies outcomes.
4. Deterministic where nothing is at stake; use Qwen when judgment is actually needed.
5. Small, testable validation deltas. Current ladder: supervised 5 min -> inspect -> 10 min -> inspect -> 30 min. Do not skip rungs.
6. The long-term target is not a scripted bot. It is a coherent persistent artificial character with needs, memory, identity, curiosity, comfort/coziness, survival judgment, reflection, planning, and controlled variation.
7. In-game thought UI shows exactly the last 3 short user-facing entries, newest at bottom. These are concise situation/intention/action/outcome summaries, not hidden chain-of-thought.

CURRENT ARCHITECTURE
A) Native C++ bridge in src/do_turn.cpp
- Enabled only when NOVA_BRIDGE_DIR is set.
- File IPC: command.json plus immutable response-<id>.json.
- Movement calls real avatar_action::move.
- Door open calls native CDDA map.open_door.
- Eat/drink call avatar_action::eat.
- Pickup obtains a real item_location, with a validation safety gate preventing fallback-to-wield/disposal-menu behavior.
- Snapshot telemetry includes absolute coordinates, moves, hunger, thirst, sleepiness, stamina/max, stored/healthy kcal, pain, morale, activity id, indoors, local 5x5 terrain/passability/door metadata/items, nearby creatures, inventory consumables.
- Nova panel in src/panels.cpp reads NOVA_BRIDGE_DIR/nova-thoughts.txt.

B) Python controller nova_runtime/nova_agent_beta.py
- Maintains local world model, visits, known tiles, remembered blocked edges, recent positions/actions, active goal/intention, no-progress counters.
- Qwen calls real local Ollama /api/chat.
- Qwen request uses keep_alive="30m".
- Raw model requests/responses and Ollama timing metrics are written to nova-model-trace-*.jsonl.
- Empty frontier exploration has a deterministic fast path.
- Important/relevant scenes call Qwen.
- Final dispatch allowlist on this validation branch:
  observe, move_one_tile, open_adjacent, wait_one_turn, pickup_consumable, eat_best_food, drink_best.
- No sleep/equip/combat is allowed by the current validation controller.
